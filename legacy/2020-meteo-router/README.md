# Метеорологический router prototype (2020)

Исторический прототип первоначального репозитория `meta`: экспериментальная маршрутизация синоптических/аэрологических/BUFR-пакетов по метаданным и условным БД.

Код перенесён из корня без функционального развития. Он не относится к F2RE Project Control, не входит в offline/meta-bundle и не участвует в текущем CI. Сохранён только для истории репозитория.
